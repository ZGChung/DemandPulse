## 执行原则

- **先做能直接带来「信任」和「留存」的**：真实数据、图表、Onboarding、我的需求、邮件。
- **Claude Code 真实集成**是核心价值，但依赖外部 API/资质，与 P0/P1 可并行调研。
- 每完成一项在本表中更新状态，并同步 `doc/current_status.md`。
