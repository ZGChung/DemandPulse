# Linear Research Sources

## Primary sources

1. Linear docs, Integration Directory
   URL: https://linear.app/docs/integration-directory
   Notes:
   - Linear's directory includes first-party and third-party integrations.
   - Linear recommends building with the API and using OAuth.
   - Linear says it accepts integrations it considers useful to the community and built by formal companies.
   - Submission flow is manual: Google Form plus assets to `integrations@linear.app` or linked in the form.

2. Example Linear listing: Neat
   URL: https://linear.app/integrations/neat
   Notes:
   - Confirms common listing structure: headline, overview, how it works, configure section, website, category, contact.

3. Linear Developers
   URL: https://developers.linear.app
   Notes:
   - Relevant technical destination for the eventual API and OAuth implementation work.

## Submission facts captured from Linear docs

- Recommended auth pattern: OAuth
- Submission email: `integrations@linear.app`
- Submission method: Google Form
- Asset support: Linear provides a Figma template for integration assets
