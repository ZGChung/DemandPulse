# GitHub Marketplace Asset Spec

Source: https://docs.github.com/en/apps/github-marketplace/listing-an-app-on-github-marketplace/writing-a-listing-description-for-your-app

## Required images

- Logo: at least `200 x 200`
- Feature card background: `965 x 482`
- Screenshots: up to 5 images, all with the same aspect ratio, each at least `1200px` wide

## Required presentation notes

- Use a square logo and keep it centered.
- Prefer a transparent logo background.
- Avoid text inside the logo.
- Make the feature card visually distinct and readable.
- Show real product UI in screenshots.
- Keep screenshot captions short.

## URL checklist

- Support URL
- Privacy policy URL
- Optional docs URL
- Optional company URL
- Optional status URL
- Setup URL if using a GitHub App
- Installation URL only if using an OAuth app
