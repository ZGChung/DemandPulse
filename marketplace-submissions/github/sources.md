# GitHub Marketplace Research Sources

## Primary sources

1. Drafting a listing for your app
   URL: https://docs.github.com/en/apps/github-marketplace/listing-an-app-on-github-marketplace/drafting-a-listing-for-your-app
   Notes:
   - Draft listings require a public app.
   - Listing creation starts from GitHub `Settings` -> `Developer settings`.
   - Review is requested after the draft is complete.

2. Writing a listing description for your app
   URL: https://docs.github.com/en/apps/github-marketplace/listing-an-app-on-github-marketplace/writing-a-listing-description-for-your-app
   Notes:
   - Requires support and privacy URLs.
   - Logo must be at least `200 x 200`.
   - Requires logo, feature card, introductory description, and screenshots.

3. Requirements for listing an app
   URL: https://docs.github.com/en/apps/github-marketplace/creating-apps-for-github-marketplace/requirements-for-listing-an-app
   Notes:
   - App must provide value beyond authentication.
   - Valid contact info, pricing, privacy policy, and support path are required.
   - Apps must handle plan-change and cancellation events through the Marketplace API.
   - Paid apps have installation thresholds and publisher-verification requirements.

4. Setting pricing plans for your listing
   URL: https://docs.github.com/en/apps/github-marketplace/listing-an-app-on-github-marketplace/setting-pricing-plans-for-your-listing
   Notes:
   - Plans can be free, flat-rate, or per-unit.
   - Paid plans require monthly and annual pricing.
   - Paid plans require request verification.

5. Applying for publisher verification for your organization
   URL: https://docs.github.com/en/apps/github-marketplace/github-marketplace-overview/applying-for-publisher-verification-for-your-organization
   Notes:
   - Needed for paid plans or a marketplace badge.
   - Requires organization ownership, 2FA, and a verified domain.

6. Submitting your listing for publication
   URL: https://docs.github.com/en/apps/github-marketplace/listing-an-app-on-github-marketplace/submitting-your-listing-for-publication
   Notes:
   - Submission is triggered from the listing overview page with `Request publish`.
   - An onboarding expert follows up during review.

## Practical conclusion

GitHub Marketplace is a viable future channel only if DemandPulse ships a GitHub-native app. The existing Claude Code plugin is not directly listable there.
