# Additional Marketplace and Distribution Channel Summary

## Visual Studio Code Marketplace

- What it is: The main discovery channel for VS Code extensions.
- Submission complexity: Medium. Requires packaging an extension, publisher setup, and marketplace-compliant metadata.
- Potential impact: High if DemandPulse ships an editor-native extension because VS Code is a primary surface for developer workflow tooling.
- Source: https://code.visualstudio.com/api/working-with-extensions/publishing-extension

## JetBrains Marketplace

- What it is: Distribution channel for plugins across JetBrains IDEs.
- Submission complexity: Medium to high. Requires a JetBrains plugin, marketplace metadata, and review compliance.
- Potential impact: High for commercial developer tooling teams that work in IntelliJ-based IDEs.
- Source: https://plugins.jetbrains.com/docs/marketplace/plugin-upload.html

## Raycast Store

- What it is: Curated extension store for Raycast productivity and developer workflows.
- Submission complexity: Medium. Requires extension packaging plus store-review readiness.
- Potential impact: Medium. Smaller reach than VS Code, but strong density of power users and developer early adopters.
- Source: https://developers.raycast.com/basics/prepare-an-extension-for-store

## npm Registry

- What it is: The default package distribution channel for JavaScript and Node.js tools.
- Submission complexity: Low. Requires a publishable package and account setup.
- Potential impact: Medium to high if DemandPulse exposes a CLI, SDK, or installable integration helper.
- Source: https://docs.npmjs.com/creating-and-publishing-scoped-public-packages/

## Product Hunt

- What it is: A launch and discovery channel for new developer products rather than a plugin marketplace.
- Submission complexity: Low to medium. Mostly a launch-ops and storytelling exercise.
- Potential impact: Medium. Good for awareness spikes, weaker than an in-product marketplace for sustained install intent.
- Source: https://www.producthunt.com/launch/
