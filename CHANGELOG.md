# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- SEO optimization: sitemap.xml, robots.txt, structured data (JSON-LD), meta tags
- Comprehensive developer API documentation (doc/API.md)
- Linear and GitHub marketplace submission packages
- Additional distribution channel research (VS Code, JetBrains, Raycast, npm, Product Hunt)
- Claude Code plugin v2.1.0 with improved metadata and installation experience

### Changed

- README improvements for developer attraction

## [0.1.0] - 2026-03-20

### Added

- Real-time dashboard with demand overview
- Requirement statistics and trending clusters
- Claude Code integration for data collection via plugin
- Mock Claude Code integration for testing
- AI-powered requirement processing
- Privacy-first design with user consent
- User authentication with NextAuth.js + GitHub OAuth
- PostgreSQL database with Prisma ORM
- SQLite support for development/testing
- CI/CD pipeline with GitHub Actions
- Automated deployment to Vercel
- Comprehensive security hardening (CORS, headers, validation)
- Structured logging and monitoring
- End-to-end testing framework
- Comprehensive test suite (55 suites, 1200+ tests)
- Localization support (English, Simplified Chinese)

### Features

- `/demandpulse:share` command for explicit requirement sharing
- Optional stop-hook auto-submit for power users
- Anonymous and account-linked submission modes
- Trends visualization dashboard
- Requirement submission and tracking
- Admin analytics and audit logs
